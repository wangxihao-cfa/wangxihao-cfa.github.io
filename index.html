01
Private Equity · Portfolio Monitoring

Private equity portfolio monitoring platform.

An AI-powered portfolio monitoring platform for private equity, built on a unified data model powered by Snowflake and serving funds with $4T+ in aggregate NAV. Internally, it powers the firm's profitability analysis and reporting; externally, it delivers client-level portfolio monitoring to LPs — cash flow projection, commitment pacing, and performance analytics. Natural-language questions in, auto-generated charts and conclusions out — grounded by RAG and agent skills, zero hallucination.

The problem

Private equity funds representing $4,000B+ in aggregate NAV needed profitability and portfolio answers that manual reporting couldn't keep up with — a one-week cycle, prone to input errors, and unable to answer questions on demand.

How I built it

A unified data model on Snowflake bringing disparate sources into one validated, lineage-tracked foundation; an LLM layer with RAG and agent skills so clients ask questions in plain language and get charts and conclusions back; internally, the same stack powers the firm's profitability analysis and the company-wide fund allocation reporting system.

Why it holds up

Every output is grounded in source data with zero hallucination, attribution reconciles to the total, and reporting that took a week now runs in minutes — with a trail that can be audited.

02
Private Equity · Secondaries Valuations

PE fund valuation & cash flow projection.

Owner of the firm's cash flow projection model — built end to end on Monte Carlo simulation, where every parameter is modeled independently with quantitative and machine-learning methods. Alongside it: Python valuation models (ValueAlt), CECL methodology, and a data-driven ESG framework — purpose-built for the secondary market, where NAV precision and forward cash flow estimates set the price.

The problem

In private markets, forward cash flows decide valuation — and in the secondary market they set the price. Off-the-shelf assumptions were too coarse for the fund-level NAV precision the business needed.

How I built it

Owned the firm's cash flow projection model end to end: a Monte Carlo engine where every parameter is modeled independently with quantitative and machine-learning methods — no hand-waved inputs.

What it enabled

Portfolio-wide liquidity and cash flow forecasts, Python valuation models (ValueAlt), the CECL methodology, and a data-driven ESG framework across all private assets.
